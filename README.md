# Hong Kong Birthday Trip 2026

Mobile-first static trip planner for the Hong Kong birthday trip, August 26–29, 2026.

## Traveller features

- Today mode with the next stop and trip countdown
- One-tap Google Maps navigation
- Local completion, skip, and postpone states
- Rain, tired, and long-queue Plan B modes
- Time-sensitive confirmation checklist
- Airport departure countdown
- Installable offline PWA

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- GitHub Pages

## Local development

```bash
mise install
pnpm install
pnpm dev
```

`mise.toml` pins the Node.js and pnpm versions used by this project. If mise is
not activated in your shell yet, run commands with `mise exec --`, for example
`mise exec -- pnpm dev`.

## Build

```bash
pnpm build
```
